# Green API

Текстовый мессенджер для Telegram. Пользователь входит по данным инстанса GREEN-API, создаёт чаты по номеру телефона и обменивается только текстовыми сообщениями.

## Запуск

### Что нужно заранее

- Node.js 18 или новее и npm.
- Инстанс GREEN-API для Telegram: `idInstance` и `apiTokenInstance`. Их вводят на экране входа, в файлы проекта они не записываются.
- Хост API. Для обычного инстанса это `https://4100.api.green-api.com`. Если в кабинете GREEN-API указан другой хост, используйте его.

### 1. Установить зависимости

В корне репозитория:

```bash
npm install
```

Команда ставит React, Vite и остальные пакеты из `package.json` в локальную папку `node_modules`.

### 2. Создать файл окружения

Скопируйте шаблон:

```powershell
copy .env.example .env
```

На Linux и macOS:

```bash
cp .env.example .env
```

Откройте `.env`. Клиент читает из него только одну переменную:

| Переменная | Зачем |
| --- | --- |
| `VITE_API_URL` | Хост инстанса, без завершающего слэша. Пример: `https://4100.api.green-api.com` |

`ID_INSTANCE` и `API_TOKEN_INSTANCE` в шаблоне лежат только как памятка. Приложение их не подставляет и не отправляет в сборку. Файл `.env` в репозиторий не коммитится.

Если `VITE_API_URL` пустой, приложение не запустится и сообщит: «Не задан VITE_API_URL». После правки `.env` перезапустите dev-сервер: Vite читает переменные при старте.

### 3. Запустить режим разработки

```bash
npm run dev
```

Сервер Vite откроет приложение по адресу http://localhost:5173. Страница обновляется сама, когда меняется код.

### 4. Войти и проверить переписку

1. Откройте http://localhost:5173. Это экран входа, маршрут `/`.
2. Введите `idInstance` и `apiTokenInstance` своего инстанса и нажмите «Войти».
3. Откроется `/messenger`. Введите номер телефона цифрами, без плюса и скобок, например `79876543210`, и создайте чат.
4. Напишите текст и отправьте его. Ответ из Telegram появится в этом чате.

Учётные данные живут в `sessionStorage` текущей вкладки. Чаты сохраняются в `localStorage` отдельно для каждого `idInstance`.

### Сборка и проверка

```bash
npm test
npm run build
npm run preview
```

- `npm test` запускает модульные тесты Vitest.
- `npm run build` проверяет TypeScript и собирает статику в папку `dist`.
- `npm run preview` отдаёт эту сборку локально, чтобы посмотреть её до выкладки.

На хостинге любой неизвестный адрес, включая `/messenger`, должен отдавать `index.html`. Иначе обновление страницы переписки не откроет приложение.
